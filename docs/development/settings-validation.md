Both final joins were SIGINT exit 0. A byte scan of the 35 retained run files (state, logs, request files, relay database) after the joins found none of the dummy credential, the two native proofs or the invitation. Captured model request bodies were written outside that run directory.

A repeated remote stress (six fresh Hosts, 50 sequential Snapshot/denial requests each) answered all 300, median 15 ms. Before that, the driver lost about one request in 40: its envelope `created_at` was taken a millisecond after the body's `issued_at` with the same 25 s lifetime, so the envelope could expire after `expires_at`, which the Host correctly records as a terminal rejection without a reply. Clients must keep the envelope expiry at or before the body `expires_at`; the loss is silent by design.
