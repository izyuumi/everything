The shared Foundation wire decoder accepts `kind: "remote_task_finished"` with one `report` object. This matches the `ConversationEvent::RemoteTaskFinished` shape in the optional Worker implementation merged through [#119](https://github.com/izyuumi/everything/pull/119); Rust's boxed report adds no extra JSON wrapper. This decoder adds no Worker/Host execution or whole-issue acceptance claim. Existing event and encrypted synchronization handling remain unchanged.

Report, source and usage objects reject unknown fields. Optional Rust fields accept null or omission. Model/tool counters fit UInt32; token counters retain the full UInt64 range.

A result source requires its exact result digest and finish timestamp, excludes Rejected outcome, and binds any quarantine digest to that result digest. Nonzero artifacts require quarantine metadata. Unknown and Rejected have no artifacts or quarantine digest. A rejection source requires a nonempty control-free reason within 256 UTF-8 bytes, Rejected outcome, no finish timestamp and exactly default usage, including absent reserved-output accounting. Supplied usage is informational and cannot refund native reservations.

This decoder validates data shape and bounds. It authenticates no worker source, admits no native result, creates no receipt, acknowledges no result, grants no permission and starts no execution. The existing encrypted transport and authoritative Host/Agent/Scheduler remain responsible for those boundaries. The report is untrusted external output, not an assistant response or user instruction.
