# Private Settings socket admission

The Unix final socket unit consumes a genuine Prepared frame and retained input in the existing total16 relay window. It does not expose a Source/guard/frame factory or change the session selector. One opaque mutable loan borrows the actual counted cell, and its constructors are confined to the final driver. Slot/window/physical socket/Source associations, the original task join and actual successful current transaction precede loan construction. Root supplies only the named crate-private exports consumed by the real remote writer and Store failure consumer.

Before the final wait, the exact bounded prepared frame is encoded once and retained in its counted cell. The blocking final worker invokes checked Main Deferred/current/one-COMMIT and returns finite Source/slot association plus the complete actual result. Its actual sender and Host guard are separate from shared input/output. The outer driver owns the receiver. The original handle and task ID remain registered through true join; the whole returned result is stored before receiver.try_recv. Failure, cancellation and Drop first destroy receiver/parcel and any registered lock waiter. The running original worker remains retained and is joined on orderly cleanup. No terminal object owns a Host mutex guard.

The driver captures one absolute five-second write deadline and prebuilds its exact Sleep inside the loan. The remote writer prebuilds its own cancellation waiter and polls that loan-owned timer before current admission; readiness and flush wait on the same absolute budget without renewal. On its first poll it registers those actual wakeups and negative stop conditions, then the loan runs the actual six-family no-SQL lifetime checker under the delivered uninterrupted guard. Bounded state, stop, physical identity and original deadline checks run before guard destruction. The post-current check compares that same captured absolute deadline, so the budget also covers the synchronous current check. The guard is destroyed immediately before the direct readiness poll on the same physical socket, with no application await, serialization or allocation between them. Pending is admitted uncertainty. Successful readiness moves the original preencoded Message once into start_send; poll_flush preserves the actual result. Later cancellation cannot prove that no bytes were sent.

Only the actual remote writer constructs write outcomes. They retain the genuine current/remote/stop/panic/flush result, physical progress and socket identity outside Source Arc. WriteReturn has one optional whole payload containing outcome first and the same loan last. Both register and Drop take that complete pair once and install the whole outcome nonfallibly in the cell before any observation or latch. Return Drop adds an actual secondary abandonment marker without replacing its primary result. Remote future Drop releases the guard, closes the exact socket, destroys socket/message copies and uses the same outcome writer. Direct loan Drop retains an actual loan-abandonment cause only when no actual outcome has already been registered.

Every stop destroys local frame copies while the full Source and charges remain counted. Waiting lock futures are stripped before every terminal archive. Actual final worker errors, JoinError, delivery errors, rollback/commit ambiguity and caught panic payloads remain owned. No generic error implies NoEffects, retry permission or cleanup. Successful flush leaves the full affine Source, Bind parent/creator and Work/private/Supervisor charges retained. Private RelayAccepted, expiry/ACK return, creator-LAST closure and honest composite drain require separate source; no ordinary removal or slot reset applies to these cells.

There is no session caller or private activation in this slice. Both existing modes remain OrdinaryOnly. A later real accepted dispatcher must compose the supplier, existing Work events, Supervisor adoption and BUILD tickets, retain each complete result, pin one final driver across select iterations and disable an actually empty Work branch until genuine registration re-arms it. This is a source contract, not compiler, transported behavior, security or production-readiness evidence. Independent full source review, integrated supported CI and focused manual runtime verification are still required. No new automated tests were introduced.
