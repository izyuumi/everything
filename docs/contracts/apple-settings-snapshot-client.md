# Explicit Apple Snapshot client

The Connected Host values section explicitly reads the existing endpoint-free Snapshot DATA after a genuine current [Bind observation](apple-settings-bind-client.md). It uses the same ReplicaService, identity, relay pump/receiver and AppModel control Task. The Host private sender remains incomplete; this client source establishes no actual transported response, native UI acceptance or issue completion.

## Genuine parent and original gesture

Bind association creation now retains the readable-key sequence from its genuine Access projection before the heavy Access cache can disappear. Snapshot requests use exactly that nonempty, sorted sequence of at most five Host keys. It is a historical request ceiling, never actual current R or permission. The Host [Read qualifier and Snapshot BUILD](settings-read-replies.md) must still check every requested key in current R before capture/publication and final sending.

Before its owned Button Task, AppModel checks actual UIKit activity, existing scene/platform latches, visible Settings surface, covers, tab/path, current connection and exact originating binding handle. A one-use MainActor Snapshot gesture captures ContinuousClock before wall, a query UUID, actual Service, opaque scope token and binding handle. Its immutable input has no caller-settable constructor. These are timing/correlation data, not authority.

Service intake requires the same real scope and retained, unretired association with its actual private parent and fixed deadline. It reserves the existing single Access/Bind/Snapshot/Inspection pending cell and one cell in the total16 map before construction or crypto. Only the parent projection's factory can read its private parent, after an isolated Service gate checks exact projection/association/scope/pending identity and spends the original capture flag once. No caller-supplied parent, generation, raw-body getter or native Owner DTO is accepted.

Let Ws/Ms be the gesture's first floors, B the actual Bound expiry and Dp its retained parent deadline. Qs=min(Ws+30000,B) and Ds=min(Ms+(Qs-Ws),Dp), with checked positive signed-range intervals. Preparation, receive, projection and cache retain those original bounds. The new UI branch uses Bound/Snapshot clocks rather than the earlier bootstrap Access30s guard; existing Access and Bind branches keep their guards. No clock sample, retry, response or reconnect creates now-plus-remaining.

## Same send window and actual return

One typed map still counts ordinary sends and the single private original together, at most16. Snapshot uses one original ciphertext, whose ID differs from its query and is checked against every registered outbound message ID and pending ACK. Private intake has no durable ordinary outbox row or offline queue. The same existing pump prepares and sends once; no new task, socket, retry loop, re-encryption or parent reset is introduced.

The original cell records send-started, actual send-returned, Accepted, real reply-helper return and one-way failure separately. Reply consumption cannot erase the encrypted ID needed by late Accepted. Private Accepted affects only that exact RAM owner; ordinary Accepted still commits its original SQL and releases only after real send return. Normal Snapshot release also requires the same current scope. Uncertainty or retirement retains its original owner until the old socket group actually returns; close/cancel flags do not prove joins. Unsent cleanup waits for actual preparation return. A retained pending identical input returns its original handle first. Snapshot now also owns a native `OSAllocatedUnfairLock<Bool>` once bit per immutable capture, shared with the [Inspection capture rule](apple-settings-original-inspection-client.md#original-target-and-genuine-parent). After actual capacity, fixed-parent and vacant-key checks it is spent before a new pending owner or crypto. Failure, retirement and interleaved captures never reset it; the shared last-input marker is not the sole fence. It grants no authority and adds no ID set, Task or queue.

The Bind association is released when it is retired, its scope retires or its parent expires; Snapshot then requires a new Bind. A new explicit read is an observation, never mutation retry, Host Close, NoEffects or evidence that a Host creator ended. Existing surface retirement also cancels its originating binding; no known-parent/recovery UI is invented.

## Read-only values and freshness

One bounded RAM cache holds only the typed display, full public Host/local identities, opaque original handles, weak scope and original response/parent-clipped fences. It retains no raw reply/tree/frame/proof, parent, generation, Service or socket. E=min(Qs,headerExpiry); cache deadline remains Ds-(Qs-E), without renewal. A payload marked stale stays stale. Actual wall observation is not causal ordering or current permission.

AppModel adopts current copied values only for its exact original handle/capture, surface epoch, connection scope and fixed clocks. Native literal text shows the exact requested entries, observed revision/time, default/desired/effective, state and finite unavailable reason. Typed null dimensions means backend default; absence of an effective value remains distinct. No endpoint, credential reference/presence, secret, provider session, arbitrary JSON, writable control or model request is exposed.

Scene/tab/cover/path/connection retirement synchronously stales copies and cancels the same owned control Task. Original returned handles are cancelled on that owner; existing scene/disconnect/disable paths capture and join the same Task after Service stop. A successful offline refresh can return an explicitly stale observation. A failed or cancelled refresh clears the copied value display, including when an observed trust invalidation clears the Service cache before view-state construction can finish. Genuine denial replaces values with its finite reason; observed revocation/pin mismatch or new Access replacement/reduction clears values. The local This iPhone preferences, notification owners, privacy covers and independent Host lifetime are preserved.
