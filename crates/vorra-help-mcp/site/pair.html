Pair this iPhone with Vorra

This pairing code opens the Vorra app. If you are reading this page, Vorra is not installed on this iPhone yet.

  1. Install Vorra for iPhone. It is in TestFlight beta, so ask the owner of the Vorra host for an invitation.
  2. On the Mac, run vorra pair again to show a fresh code.
  3. Scan the new code with the Camera app and approve the iPhone on the Mac.

The secret part of the pairing code never reaches this website. This page runs no scripts and loads nothing else.
